# Contributing

## Development Environment
- Java 21
- Purpur 26.2
- BentoBox 3.20.x
- Geyser
- Floodgate

## Design Principles
- Do not modify BentoBox source code.
- Java Edition players keep the original BentoBox experience.
- Bedrock Edition players use native Bedrock Forms.
- Prefer BentoBox API over custom implementations.

## Commit Messages
feat:
fix:
docs:
refactor:
test:
build:
chore:

## Pull Requests
- One feature per pull request.
- Keep changes focused.
- Update documentation when necessary.
